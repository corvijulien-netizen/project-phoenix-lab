# Camino Virtuel — Phoenix Lab

Première version codée du nouveau cap de Projet Phoenix :

> Les kilomètres sont réels. Le voyage est virtuel.

Le tableau de bord transforme chaque kilomètre réellement marché en progression sur un parcours d’environ 3 000 km entre Rome et Santiago.

## Cette version

- identité provisoire **Camino Virtuel**
- accueil inspiré d’un carnet de pèlerinage contemporain
- carte illustrée Rome → Santiago
- étape virtuelle du jour et illustration originale
- suivi Marche, Nutrition, Sommeil et Journal
- carnet du pèlerin avec 60 tampons de 50 km
- future Compostela virtuelle au 60e tampon
- responsive ordinateur, tablette et mobile
- données actuelles clairement identifiées comme une démonstration

## Données

Les valeurs de cette première version sont centralisées dans `lab.js`. Le branchement aux exports de santé et au tracé géographique sera réalisé dans une étape ultérieure.

Le site public `project-phoenix` reste indépendant et n’est pas modifié par les expérimentations du Lab.
